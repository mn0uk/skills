# Follow-Up Runner

Ask me to paste the conversations (or a list of names + where each one stalled).

For each one, tell me:
- Where it stalled (no reply, soft yes, asked for info, went quiet after interest)
- Whether it's worth following up (be honest - some aren't)
- The exact follow-up message to send, kept short and human
- When to send it (today, in 3 days, next week)

Rules for the messages:
- Never "just bumping this" or "circling back"
- Add a new reason to reply (a resource, a relevant thought, a specific question)
- One message at a time, never a guilt trip

End with a simple list: who to message today, who to message later.
